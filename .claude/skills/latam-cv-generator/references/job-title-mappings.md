# Job Title Mappings: Uncommon → Common Alternatives

When a job posting uses an uncommon or specialized title, use this guide to select a more common title for the candidate's current experience that still demonstrates relevant skills.

---

## General Principles

### 1. Seniority Preservation
The common alternative should match the seniority level of the uncommon target title.
- If target is "Senior DevOps Engineer" → use "Senior Software Engineer"
- If target is "Lead Data Engineer" → use "Lead Software Engineer" or "Senior Data Analyst"

### 2. Skill Overlap
The alternative title should share 60-80% of core skills with the target role.
- DevOps Engineer → Software Engineer (both code, understand infrastructure)
- Customer Success Manager → Account Manager (both manage client relationships)

### 3. Industry Flexibility
The alternative can be from an adjacent industry if skills transfer naturally.
- Growth Hacker (target) → Digital Marketing Manager (alternative, different industry OK)

### 4. Natural Progression
The alternative should be a believable role that naturally leads to the target position.
- If target is "Revenue Operations Manager", alternative "Operations Manager" or "Business Analyst" makes sense as a stepping stone

## Seniority Level Mapping

When the target title includes seniority modifiers, preserve them in the alternative:

| Target Seniority | Alternative Seniority | Examples |
|------------------|----------------------|----------|
| Junior/Associate [Title] | Junior/Associate [Alternative] | Junior DevOps Engineer → Junior Software Engineer |
| [Title] (Mid-level, no modifier) | [Alternative] (Mid-level) | DevOps Engineer → Software Engineer |
| Senior [Title] | Senior [Alternative] | Senior SRE → Senior Systems Engineer |
| Lead/Staff [Title] | Lead/Senior [Alternative] | Lead Platform Engineer → Lead Software Engineer |
| Principal [Title] | Senior/Lead [Alternative] | Principal ML Engineer → Senior Software Engineer |

## Usage Examples

### Example 1: Technology Role

**Target Job:** Senior DevOps Engineer at a fintech company

**Analysis:**
- Seniority: Senior
- Uncommon title: DevOps Engineer
- Industry: Fintech (financial technology)

**Candidate Current Title:** Senior Software Engineer (Backend)
**Candidate Current Company:** Globant or Mercado Libre (tech companies)

**Rationale:** Senior Software Engineer (Backend) naturally progresses to Senior DevOps Engineer. Backend development includes infrastructure work, CI/CD, and system reliability—core DevOps skills.

---

### Example 2: Business Role

**Target Job:** Revenue Operations Manager at a SaaS company

**Analysis:**
- Seniority: Manager level
- Uncommon title: Revenue Operations
- Industry: SaaS

**Candidate Current Title:** Senior Business Analyst or Operations Manager
**Candidate Current Company:** Accenture, Deloitte, or tech company

**Rationale:** Business Analyst with operations focus or Operations Manager provides the analytical and process skills needed for RevOps. Natural progression into revenue-focused role.

---

### Example 3: Marketing Role

**Target Job:** Growth Hacker at an e-commerce startup

**Analysis:**
- Seniority: Mid-level (no modifier usually means mid)
- Uncommon title: Growth Hacker
- Industry: E-commerce

**Candidate Current Title:** Digital Marketing Manager or Marketing Analyst
**Candidate Current Company:** Mercado Libre, Mercado Pago, or e-commerce retailer

**Rationale:** Digital Marketing Manager with analytics focus covers growth marketing fundamentals (acquisition, conversion, retention). Demonstrated ability to drive metrics.

---

### Example 4: Data Role

**Target Job:** Machine Learning Engineer

**Analysis:**
- Seniority: Mid-level
- Uncommon title: Machine Learning Engineer
- Industry: Tech/AI

**Candidate Current Title:** Software Engineer or Data Engineer
**Candidate Current Company:** Globant, IBM, or tech company

**Rationale:** Software Engineer with strong programming skills or Data Engineer with data pipeline experience provides foundation for ML Engineering. ML roles require solid coding background.

## Special Cases

### Very Niche Roles

For extremely niche roles (e.g., "Web3 Community Architect", "Prompt Engineer"), use a two-step approach:

1. **Identify core function:** Community Management + Technical OR AI/ML + Engineering
2. **Use common title from that function:**
   - "Web3 Community Architect" → "Senior Community Manager" or "Community Lead"
   - "Prompt Engineer" → "Software Engineer" or "AI Engineer" (if exists) or "Product Manager"

### Newly Created Roles

For titles that didn't exist 3-5 years ago:
- Ensure candidate's previous titles use established terminology from when they would have held those roles
- Example: If target is "Prompt Engineer" (very new), candidate's 2020 role should NOT be "AI Engineer" (also relatively new then), better to use "Software Engineer"

### C-Level Titles

For C-level targets (CTO, CMO, CFO, etc.):
- Candidate should be at **Director or VP level** in the same function
- Example: Target CTO → Candidate "Director of Engineering" or "VP of Engineering"
- Do NOT attempt to map from unrelated areas (e.g., VP of Sales → CTO doesn't work)

### Industry-Specific Titles

Some titles are industry-specific and should map accordingly:
- "Petroleum Engineer" is standard in energy, not uncommon
- "Medical Science Liaison" is standard in pharma, not uncommon
- These don't need mapping; use the same or similar title

### When NOT to Map

Use the target title directly (no mapping) when:
1. **Target title is already common:** "Software Engineer", "Product Manager", "Marketing Manager", "Business Analyst", "Financial Analyst"
2. **Industry-standard title:** "Petroleum Engineer" in energy, "Clinical Research Associate" in pharma
3. **Candidate's current title can match exactly** without seeming overqualified

## Validation Checklist

When using this mapping guide, verify:
- [ ] Alternative title maintains same seniority level as target
- [ ] Alternative title shares 60-80% of required skills
- [ ] Alternative title is a believable predecessor role
- [ ] Alternative title is more common than target title
- [ ] Alternative title existed during the candidate's tenure (important for newly created roles)
- [ ] Alternative title makes sense at the candidate's current company
