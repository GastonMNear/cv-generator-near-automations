# Share the Drive folder for deleted Clay rows

Create a Google Drive folder (e.g. "PlayDeletedRows" / "Clay Deleted Rows"), organised per campaign,
and share it with Hector so he can upload the CSV exports of rows deleted during cleanup.

**Why:** **Blocks Hector.** The agreed procedure is that every batch of rows is exported to CSV
*before* being deleted from Clay — that's the only recovery path if a filter deletes something it
shouldn't. Hector now owns the cleanup 3x/week but has nowhere to put the exports until this folder
exists. Small task, real blocker. Done = folder created, structured per campaign, shared with Hector.

**Timing:** "ahora te voy a pasar una carpeta" — said during the Aug 10 call, so intended same-day;
no formal deadline.

> "Entonces yo ahora te voy a pasar una carpeta en Google Drive, donde la idea es que vayamos
> poniendo todo lo que fuimos eliminando de cada una de las campañas."
