# Draft the 3 re-engagement emails, set the variables, load leads, start sending

Write three emails for the re-engagement subsequence, set them as Smartlead lead-level variables,
load the qualifying leads, and start sends.

**Why:** Daniel was short on launches — *"yo necesito embutir lanzamientos y esta semana vamos cortos"*
— and nothing can send until the variables exist. This is the delivery end of
[[wiki/tasks/2026-08-24-smartlead-remove-recontact-limit]], which holds the full mechanism design.

**Copy direction, as decided:**
- **Do not reference prior contact.** Daniel found it *"patético"* / *"re idiota."*
- **Lead with post recency:** *"vi la publicación hace X días de tal rol para tal empresa"*, then offer
  to strengthen their pipeline with high-profile candidates.
- **Pull the job post date as a variable.**
- Non-creepy justification: LinkedIn shows "meet the hiring team", so knowing who owns the req is fair game.
- **Subject line to be tested, not finalised** — *"saw your role search on LinkedIn"* floated.
- Overall: *"algo muy parecido al baseline, pero cambiándolo un poco, porque no le queremos mandar lo mismo."*
- **One shared angle, not a per-role split** — the Eng vs Sales/Marketing wording split belongs to the
  No-HM experimental copy, not to this campaign.

**Variables:** `email1_re-engage` / `email2_re-engage` / `email3_re-engage`, replacing baseline
email1/2/3, fired by a tag on the lead. **Recency window: last 1–2 weeks.**
