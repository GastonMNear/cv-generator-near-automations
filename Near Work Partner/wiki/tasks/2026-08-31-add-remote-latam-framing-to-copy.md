# Say "remote LATAM talent" in the copy — starting with email 1

Rewrite the sequence copy so it **states explicitly that the candidates are remote LATAM talent**,
not US-based. Start with the **first email**, mirroring the "remote candidates" wording Hector already
added to the resume-send message.

**Why:** Hector found the gap and it's real — **the sequences never specify remote or LATAM**, so
prospects read "talent" as candidates physically in the US and **only discover otherwise when CVs
arrive**. That surfaces as friction or lost replies mid-sequence, after we've already spent the send.
Gaston confirmed he'd seen the same problem in the **C-Asian campaign** copy he was reviewing.

**Done =** email 1 (at minimum) states the remote LATAM model, across the campaigns that lack it.

**Scope is not fully mapped:** the gap was found in the main sequences and C-Asian. **Nobody checked
whether every campaign has it** — worth an audit pass as part of this.

**Timing:** No date. Hector's *"eso hay que cambiarlo"*, Gaston agreed. **Needs a date from Gaston.**

> Hector: "creo que sería bueno como que en el primero decir como remote talent ... entonces eso hay
> que cambiarlo" — *"I think it would be good to say remote talent in the first one ... so that has to
> be changed."*
> Gaston: "Yo creo que sí, he estado viendo de eso también en ... Asia creo que es"
